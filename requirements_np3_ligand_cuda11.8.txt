### np3_lig installation workflow for GPU in 4 stes. The pip requirements are listed in step 3 and are not commented with a hashtag (#)
###
### 1. Global requirements:
###
### Install CCP4 (https://www.ccp4.ac.uk/download/) and CUDA 11.8 with recommended driver (https://medium.com/@juliuserictuliao/documentation-installing-cuda-on-ubuntu-22-04-2c5c411df843)
#### Check CUDA compatibility with your driver and install a CUDA version lower than the one shown in:
#> nvidia-smi
### Install ANACONDA
### Install GCC >= 7.4.0 < 11 and build-essentials and libopenblas-dev
#> sudo apt install build-essential libopenblas-dev g++-9

###
### 2. Install python 3.9 using ANACONDA
###
#> conda create -n np3_lig python=3.9 -y
#> conda activate np3_lig
#> conda install openblas-devel -c anaconda -y
#> conda install r-base=4.4.0 r-readr r-dplyr -c conda-forge -y
## install R anticlust package - not present in conda                            
#> Rscript -e 'install.packages("anticlust",repos = "http://cran.us.r-project.org")'
## For CUDA capability also install cudatoolkit
#> conda install nvidia/label/cuda-11.8.0::cuda-toolkit -y   # use '-c nvidia' option for older versions of cuda

###

### 4. Finally install Minkowski Engine package with pip - last version - Select installation option 4.A or 4.B
###
### 4.B CUDA capability - here example with cuda 11.8
## make sure CUDA version 11.8 is installed on the system!
# check driver compatibility
#> nvidia-smi
#> nvcc --version
## Install Minkowski Engine package with pip and cuda capability
# checar versões:
#> python -c "import sys; import torch; print('Python version:', sys.version); print('Torch version:', torch.__version__); print('Torch CUDA version:', torch.version.cuda); print('CUDA available:', torch.cuda.is_available());" && gcc --version | head -n 1 | cut -d' ' -f3
#> export CXX=g++-9; # set this if you want to use a different C++ compiler
#> export CUDA_HOME=$(dirname $(dirname $(which nvcc))); # or select the correct cuda version on your system.
#> export LD_LIBRARY_PATH=$CUDA_HOME/lib:$LD_LIBRARY_PATH
#> export PATH=$CUDA_HOME/bin:$PATH 
#> export MAX_JOBS=2; # parallel compilation - prevent to much CPU assignment and process killed
# Clone Minkowski Engine repository (recommended) - https://github.com/NVIDIA/MinkowskiEngine (check for installation issues):
#> cd MinkowskiEngine
#> python setup.py install --blas_include_dirs=${CONDA_PREFIX}/include --blas=openblas --force_cuda
# Or using pip: 
#> pip install -U git+https://github.com/NVIDIA/MinkowskiEngine -v --no-deps --config-settings="--build-option=--blas=openblas" --config-settings="--build-option=--force_cuda"
